Project overview: <br>
This project's scope covers the planning, research, and implementation of a website for a hypothetical business called Vintage Stitches. Throughout the development of the website, documentation will be maintained via this READ.me file along with submission of other requested information. <br>
Vintage Stitches is a solo run business who's owner needs a framework to complete sales and recieve feedback from customers. <br>
A fully fucntioning website (considering the technical limits of not being hosted) will be created over the course of this assignment via the use of three vital frameworks. HTML is the focus of part one and will be used to add content and structure to the website. CSS will be used to format the website and improve UX. JavaScript adds functionality to the website and completes its development. <br>
<br>
Website goals and objectives: <br>
The primary goal of the website is to increase sales. Additionally, customer feedback as well as increased product interest are secondary goals.

Part 1 Details: <br>
Part one consists of planning, research, and HTML. Two proposals were put together and submitted for approval. Once a proposal was chosen, research as well as collecting of image and text assets was done. After the suitable assets where obtained and appropriate research was conducted, the HTML to the website was written and put on GitHUB. Comments in the code outline the steps forward for CSS and JavaSctipt implementation.
<br>
<br>
Part 2 Details: <br>
Added CSS to all pages. The colour scheme was fully implemented. Spacing as well as element padding and screen space ratios were improved. Image titles were added alongside hover interaction to increase accessibility. Button design was majorly improved as was the appearance of the checkout div. There is now a solid, clear design scheme and elements with which to build on with JavaScript.
<br>
<br>
POE Details: <br>
JavaScript has been implemented to add functionality to the website. The user can now view items and checkout a list of up to 20. An invoice is given to the user with price calculation. A search function allows the user to filter the catalogue items via either name or size. A map has been added to the about us section to help the user with navigation and pickup.
